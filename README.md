Healthcare patient operations and cost analyses 
project overview
This project analyse 1000 healthcare patient records to understand patient volume,
cost, diseases, payment method and outcomes.
## objective
The objective of this project is to use data analytics tools to identify healthcare 
operational and financial trends and present actionable insights.
## Tool used
Microsoft Excel
PostgreSQL / sql
Microsoft power bi 
## Project process
Data cleaning and validation in excel
Exploratory analysis using excel pivot tables
SQL analysis using PostgreSQL 
kpi and dashboard development in power bi 
cross_checking key results across excel, SQL, power bi
identifying key findings and possible business action 
## Key insights 
General department had the highest patient volume with 278 patients.
General department generate the highest revenue of pkR 1,495,890.
Asthma had the highest patient count with 186 patients.
Cardiology had the highest average bill among departments.
ENT generated the lowest department revenue at pkr 1,292,578.
Total revenue across the dataset was pkr 5,495,473.
## Data source
publicly available healthcare/clinic dataset used for educational and
portfolio analysis.
## Dashboard
The project includes an excel dashboard and 3 page interactive power bi 
dashboard with kpi cards ,charts, and slicers.
## conclusion 
The analysis provides an overview of patient demand, department performance ,
revenue ,costs,and healthcare operations using excel, SQL , and power bi .
